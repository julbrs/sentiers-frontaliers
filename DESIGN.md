# Sentiers Frontaliers Platform Design Principles

## Purpose

This document defines practical design principles for the member platform so the UI stays aligned with Sentiers Frontaliers visual identity.

The recommendations are derived from the SF identity deck direction (strong brick-red brand presence, clean light neutrals, high-contrast white typography, geometric diagonal framing) and adapted for a digital product context.

## 1) Brand Character

- Voice: trustworthy, grounded, outdoor-oriented, and community-driven.
- Visual tone: structured and confident, with restrained warmth.
- Composition: prefer clear sections and strong separators over decorative noise.

## 2) Color System

Use a compact palette and keep brand red as the visual anchor.

### Core colors

- Brand Red 700: `#8F1F24`
- Brand Red 800: `#7A181D`
- Brand Red 900 (deep surface): `#651216`
- Off White: `#FAF8F6`
- Mist Gray: `#E8E6E4`
- Charcoal Text: `#1F2937`

### Usage rules

- Header and footer: brand red surfaces with white text.
- Main app background: off-white/neutral for content readability.
- Interactive emphasis: use one accent family at a time; avoid mixing many saturated accents.
- Keep contrast at WCAG AA minimum for text and controls.

## 3) Typography

Use a two-font system to mirror the identity style:

- Display / titles: `Montserrat` (600-800)
- Body / UI text: `Source Sans 3` (400-600)

### Type behavior

- Navigation and section titles should feel compact and confident.
- Body text should remain open and readable.
- Avoid long all-caps text blocks; reserve all caps for short labels or brand marks.

## 4) Layout And Shapes

- Favor clean, modular blocks.
- Use diagonal motifs sparingly (hero/banner separators, not every card).
- Keep comfortable spacing rhythm and avoid dense interfaces.

## 5) Component Guidelines

- Header: strong brand bar, clear hierarchy between logo/title and account actions.
- Footer: stable brand anchor with utility links/icons; keep simple and legible.
- Cards/forms: neutral background, subtle borders, clear focus rings.

## 6) Accessibility And UX Baselines

- Ensure keyboard focus visibility on all actionable elements.
- Preserve semantic headings and landmark regions.
- Do not communicate status by color alone.
- Maintain touch-friendly hit areas for mobile.

## 7) Content And Imagery

- Prefer authentic outdoor/community visuals over stock-heavy styles.
- Keep icon usage functional and consistent.
- Let typography + spacing carry most of the visual hierarchy.

## 8) Implementation Constraints

For this refresh cycle, changes should remain intentionally limited:

- Update header and footer backgrounds to the brand-red system.
- Update default typography stack to the defined two-font system.
- Keep existing layout and component structure unchanged.
